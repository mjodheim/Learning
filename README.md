## 🇫🇷 Français

Ce dépôt rassemble les exercices, laboratoires et projets réalisés au fil de ma formation en **développement Full Stack**.

Le parcours a commencé avec **C#/.NET**, la programmation orientée objet, SQL Server, l'accès aux données, ASP.NET Core et Angular. Il se poursuit aujourd'hui avec **Java**, **PostgreSQL** et JavaScript, avec une progression vers **JDBC, Hibernate, Spring Boot, les API REST, les tests, Docker, TypeScript et Angular**.

L'objectif n'est pas de présenter un produit unique ni un code artificiellement parfait. Le dépôt conserve les différentes étapes d'apprentissage afin de montrer une progression réelle : comprendre les fondamentaux, appliquer les concepts dans de petits exercices, structurer des applications plus importantes, rencontrer des erreurs, les corriger et progressivement adopter des pratiques plus proches du développement professionnel.

### Progression actuelle

- 🧱 **C# / .NET** — algorithmique, POO, collections, génériques, exceptions, architecture en couches, ASP.NET Core, API REST et accès aux données.
- ☕ **Java** — fondamentaux, POO, héritage, polymorphisme, interfaces, collections et applications console structurées. Le parcours comprend désormais des exercices OOP, une médiathèque et **Heroes vs Monsters**.
- 🗄️ **Bases de données** — modélisation relationnelle, SQL Server/T-SQL, PostgreSQL, DDL/DML/DRL, jointures, agrégats et SQL procédural.
- 🌐 **Web** — HTML/CSS, JavaScript, DOM, événements, appels HTTP, TypeScript et Angular.
- 🧩 **Full Stack** — séparation Domain/DAL/BLL/API, DTO, repositories, services, injection de dépendances et consommation d'API depuis Angular.
- 🧪 **Qualité** — progression vers les tests automatisés, Docker, CI/CD et les pratiques de production.

Le dépôt continuera à évoluer avec les modules suivants au fur et à mesure qu'ils seront étudiés et pratiqués :

L'objectif est de relier progressivement ces briques dans des applications complètes plutôt que de les apprendre isolément.

## 🇬🇧 English

This repository contains the exercises, labs and projects completed throughout my **Full Stack development training**.

The journey started with **C#/.NET**, object-oriented programming, SQL Server, data access, ASP.NET Core and Angular. It now continues with **Java**, **PostgreSQL** and JavaScript, progressing towards **JDBC, Hibernate, Spring Boot, REST APIs, testing, Docker, TypeScript and Angular**.

The goal is neither to present a single product nor artificially perfect code. The repository intentionally preserves the different stages of the learning process: understanding fundamentals, applying them in small exercises, structuring larger applications, encountering mistakes, fixing them, and progressively adopting more professional engineering practices.

### Current progression

- 🧱 **C# / .NET** — algorithms, OOP, collections, generics, exceptions, layered architecture, ASP.NET Core, REST APIs and data access.
- ☕ **Java** — fundamentals, OOP, inheritance, polymorphism, interfaces, collections and structured console applications, including OOP exercises, a media-library project and **Heroes vs Monsters**.
- 🗄️ **Databases** — relational modelling, SQL Server/T-SQL, PostgreSQL, DDL/DML/DRL, joins, aggregates and procedural SQL.
- 🌐 **Web** — HTML/CSS, JavaScript, DOM, events, HTTP calls, TypeScript and Angular.
- 🧩 **Full Stack** — Domain/DAL/BLL/API separation, DTOs, repositories, services, dependency injection and Angular API consumption.
- 🧪 **Quality** — progressing towards automated testing, Docker, CI/CD and production-oriented practices.

### Repository contents

| **[HTML / CSS](./HTML-CSS)** | Web integration and layout exercises. | HTML structure, CSS styling, layout and web-interface fundamentals. |
| **[Databases](./DataBase)** | SQL Server and PostgreSQL scripts, DRL/DML exercises, relational models and procedural Northwind exercises. | Modelling, DDL, DML, DRL, joins, subqueries, aggregates, functions, procedures and procedural SQL. |

### Next steps

The repository will continue to grow as the following subjects are studied and practised:

`JDBC → UML → Hibernate / JPA → Spring Boot → REST → Java Testing → Docker → TypeScript → Angular`

The aim is to progressively connect these building blocks into complete applications rather than learning them in isolation.
